- Deletion (leaf, one child, two children)
- Minimum and maximum
- Inorder successor and predecessor
- Height and counting
- Kth smallest and kth largest
- Validation
- Lowest common ancestor

## How to use this folder

Each `.cpp` file is one question. The file name is the question in short form.
The full question is written at the top of the file.

1. Read this README.
2. Open a question file and attempt it without copying.
3. Compile and test it locally.
4. Mark it done by renaming to `<name>_done.cpp`.
5. Move on only when the basic questions here feel comfortable.

```bash
g++ -std=c++17 Max_Element.cpp -o solution
./solution
```
